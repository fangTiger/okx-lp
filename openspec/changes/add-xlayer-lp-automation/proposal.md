# Change: X Layer xStocks LP 激励自动化参与系统

## Why

X Layer 于 2026-08 启动 500 万美元 RWA 生态激励，Round 1 投放 30 万美元
（RWA-稳定币对 20 万，档期约 08-24 ~ 09-07；RWA-生态代币对 10 万，档期 08-26 ~ 09-02）。

该活动的奖励口径是**按 LP 在池内产生的手续费占比、按小时结算**，而非常见的 TVL 时间加权。
这意味着收益由「in-range 有效流动性份额」决定，而份额 ≈ 本金 / 区间宽度。
人工做市无法在 24/7 的链上市场里持续维持窄区间不出界，
也无法在美股开盘/财报事件前及时收敛风险 —— 必须自动化，且必须自带风控。

活动窗口只有约两周，奖池固定、APR 随资本涌入线性衰减，系统需要在数日内可用。

## What Changes

- 新增 `okx-lp` 项目：X Layer 上 Uniswap v3/v4 集中流动性头寸的自动化做市与激励收割系统。
- 新增能力 `xlayer-lp-automation`，包含七个子能力：
  - **活动适配**：合格池发现与链上校验、奖励密度计算、我的份额估算、奖励领取。
  - **行情与时段**：链上池价 + 标的股票行情 + 美股交易日历 + 财报事件日历。
  - **区间策略**：基于分时段波动率的带宽状态机，输出目标 tick 区间。
  - **执行**：Uniswap v3/v4 头寸的 mint / burn / collect / rebalance，含滑点与 gas 控制。
  - **对冲**：基于 LP 实时 delta 的 xStocks 永续对冲腿管理。
  - **风控**：熔断器、限额、白名单、dry-run 闸门。
  - **记账与监控**：收益归因（手续费 / 激励 / IL / 对冲）、多人合伙份额账本、告警与日报。
- 新增分阶段上线闸门：事实清单未核实完毕时系统只能 dry-run 启动。
- 新增链上头寸与 ERC20 授权的同区块只读快照，为 NPM tokenId 白名单和启动对账提供唯一合法来源。

**不包含**（明确排除）：
- 不做跨链桥自动化（资金入场走人工 + OKX 官方桥）。
- 不做自建 RPC / 自建索引器（Round 1 时间不允许）。
- 不做多地址拆分（存在反女巫风险）。

## Impact

- Affected specs: 新增 `xlayer-lp-automation`
- Affected code: 新建 `okx-lp/`（Python，沿用 `bn-monitor` 的 requests + venv + launchd 约定）
- 涉及真实资金：默认 dry-run，实盘需显式配置 + 人工确认闸门
- 外部依赖：X Layer RPC、Uniswap 合约、股票行情源、CEX 永续（对冲）、Telegram（告警）
